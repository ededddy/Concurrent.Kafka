# Kafkaflow Wrapper

Solely exists to provide easier and cleaner dependency injection code.

## Requirments
- .NET 8.0

# Other Dependencies' versions 
- KafkaFlow packages == 3.0.10
- Confluent Kafka v7.1.1
- MongoDB 6.0.2

## bench directory 
The bench directory originally used to house benchmarking projects. However, due to some of the code used is proprietary, most projects are removed from it.  

The bench directory now contains .NET projects to show how to use the wrapper package.
